# Team pictures

Put a picture of each teammate in this folder, and the app shows it in their circle instead of their initials. Pictures stay on this laptop: everything here except this file is ignored by git.

| Teammate | Name the file |
|---|---|
| Tsunade, Fifth Hokage | `tsunade.png` |
| Kakashi Hatake, Jōnin | `kakashi.png` |
| Jiraiya, Legendary Sannin | `jiraiya.png` |
| Itachi Uchiha, Akatsuki | `itachi.png` |
| Satoru Gojo, the helper (logo, hints, chat) | `gojo.png` |

- Formats: `.png`, `.jpg`, `.jpeg`, `.webp` or `.gif`, up to 2 MB each. File names are lower case.
- A square picture with the face in the middle looks best, because the circle crops the edges. About 128 × 128 pixels is plenty.
- The full name (`kakashi-hatake.jpg`, `satoru-gojo.jpg`) and the internal id (`maya.png`, `theo.png`, `priya.png`, `sam.png`) work too.
- Reload the page after adding or changing a picture. No rebuild or restart is needed.
- A teammate without a picture keeps their initials.

Use pictures you have the right to use, such as ones you drew or bought, or fan art whose artist allows personal use.
