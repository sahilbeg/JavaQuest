# FEAT-02: Launch the membership system

Fill in `BikeType`, `Membership` and `Rider` so riders get the monthly statement from the KB page. BASIC pays the $1.00 unlock fee and every minute. PLUS rides 30 minutes free and PRO rides 60 minutes free, with no unlock fee.

Only the first `rideCount()` slots of the ride array hold rides. The rest are `null`, so loop up to the count.
