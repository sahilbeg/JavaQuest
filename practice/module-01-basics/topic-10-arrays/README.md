# Arrays and 2D arrays

Teach the Riverside kiosk to read its dock sensors in `DockMap.java`. In a `boolean[]` of docks, `true` means the dock holds a bike.

1. **TODO 1:** make `countBikes(docks)` return how many docks are `true`.
2. **TODO 2:** make `firstEmptyDock(docks)` return the dock **number** of the first `false` dock. Dock numbers start at 1, so the number is `index + 1`. Return `-1` when every dock holds a bike.
3. **TODO 3:** make `totalMinutes(rides)` return the sum of all the ride minutes.
4. **TODO 4:** make `longestRide(rides)` return the biggest number in `rides`. Return `0` when the array is empty.
5. **TODO 5:** make `bikesPerStation(stations)` return an `int[]` with one bike count for each row of the 2D array.

Press **Submit** in JavaQuest, or just save the file in your IDE. The tests run on their own.
